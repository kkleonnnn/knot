## 2. Grounded 根因（file:line）

**Q5** `knot/services/semantic/compiler.py:306-307`（`compile_logicform`）：`lf.outer` 非空即无条件 `WITH r AS ({inner}) SELECT {func}(*) AS result FROM r`。当 `lf.dimensions==[]`，inner 已是标量（1 行聚合值），outer `COUNT(*)` 数那 1 行 → 恒返 1。Q25「本月盈利交易对有几个」`dimensions=["market"]` 同 wrap 数分组行=正确。

**Q24** `compiler.py:_window_col`(118-136, 行 130-133) 原样拼 `ORDER BY {order_by.field}`（无粒度变换）；`compile_helpers.py:_frame_clause`(142-150) 原样 `ROWS BETWEEN 6 PRECEDING AND CURRENT ROW`。`dimensions=["sta_time"]`(DATETIME) → `GROUP BY sta_time` 逐笔分组 + 帧按行 → 7-**笔**移动平均。**代码库 0 处 DATE 截断**（`grep DATE(` in semantic/ = 0）。∴ 真算对需 dim+GROUP BY+window order 全日粒度。

**Q28** `this_week` 不在 `_TIME_KEYS`（`compile_helpers.py:17-21`：this_year/this_year_to_latest/this_month/this_month_to_latest/last_week/last_7_days_to_latest/same_period_last_year/today/yesterday/last_month/last_year）也不在 `parser.py:18` 枚举 → `compiler.py:208` `raise CompileError("未知 time 枚举 'this_week'")`。但 `time_resolver.py:205` 已算 `this_week_mon = t - timedelta(days=t.weekday())`（仅用于推 last_week，未暴露 this_week）。

**Q18** `compiler.py:95-102 _resolve_dim_owner`（调用点 :178）：为 `user_future_amt`(base `dwd_user_future_deal`) 解析维度 `market` → :97 检查 metric 自身 base 无 market → :99 **全局搜其他 base** → 命中 `dwd_user_funding` + `dwd_user_position_history` 两 owner → :100-102 `len(owners)>=2` raise「归属歧义」→ 回退。**根因**：单指标查询的维度解析不该全局搜；`dwd_user_future_deal` 物理无 market（明细不记录交易对），应清晰拒识。

**Q13** `multi_base.py:68-70` 对每 metric 调 `_resolve_metric_date_col`（`compile_helpers.py:62-69`）；`agent_future_fee`@`ads_agent_stat` 无显式 `date_column` + dims=`["agent_id"]` 无日期列 → 返 None → raise。**数据现实**：`ads_agent_stat` = 累计画像快照（每代理一行，无日期）→ 无法时间窗 → 回退合理。
