## 2. 设计（推荐 · 待 Stage 2/3）

- **gate 一次**：`generate()` 顶部（L199 后）`is_admin = user.get("role") == "admin"`；非 admin 时 `alias_map = build_table_alias_map(catalog_loader.LEXICON)`（deferred import，同 conversations.py）。

- **fail-open**（R-脱敏-2）：alias_map 空 → text 原样（不阻断流）；pop sql / suppress sql_step 仍执行（不依赖 alias_map）。
