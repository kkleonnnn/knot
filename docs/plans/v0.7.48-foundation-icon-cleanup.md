## §2 I.medal 决策（grounded 修正 v0.5.19 承诺 → 撤回）

**背景**:docs/plans/v0.5.19 + CHANGELOG:4250/4332 记「Shared 无 I.medal；v0.6 解锁后纳入」承诺——把 AdminRecovery top-user 榜首 header 的 inline svg 迁移到 I.medal。

3. I.medal grounded 0 使用 = 真死 export。删它 + 保留 AdminRecovery trophy inline svg（Q2 VRP 例外不动）。
4. 记留痕:v0.5.19 承诺正式撤回（附本 grounded 理由），非 R-LP-v3-EX-3 拖延（是「承诺前提不成立」的撤回）。
