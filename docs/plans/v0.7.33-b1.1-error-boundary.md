## 2. Grounded 设计（workflow）

- **App.jsx**（L99-153）= 扁平 early-return「路由」：loading spinner / Enroll / Login / ForceChangePassword / 8 admin-* / ChatScreen 各独立 return，无单根 → boundary 只能 `main.jsx` 包 `<App/>`。
- **main.jsx** L10：`createRoot(...).render(<App/>)` → 改 `render(<AppErrorBoundary><App/></AppErrorBoundary>)`。
- **error_reporter.js**：`installErrorReporter()`（唯一 export）内 window.error/unhandledrejection → 私有 `_post`（POST /api/frontend-errors，`if(!token)return` 静默）+ `_shouldReport`（per-hash 1h + 5/min + 50/page 上限）。加 `export reportError(message, stack, extra)` 跑同 `_computeHash→_shouldReport→_post` 链；window.error handler 改调 reportError（byte-equal 上报）。
- **Shared.jsx**：`buildTheme(dark)` → POJO T（bg/content/card/border/text/subtext/muted/accent/warn/sans…，**无 error**）；`TOKENS_V2.err = oklch(66% 0.20 25)`（module const，同 Btn danger 源）；I 38 图标**无 warn/triangle**；`SvgPath` helper 可 one-off（不改 I dict）。
- **primitives.jsx** Btn：`{T, variant, size, icon, iconRight, onClick, ...}`；`variant="primary" icon={<I.refresh/>} onClick={()=>window.location.reload()}`。
- **Conversation.jsx**（L31-35）：`msg.loading ? <ThinkingCard/> : <ResultBlock T={T} msg=.../>` in `messages.map` → 仅包 ResultBlock 分支（问题气泡 L17-24 + 头像 L27-29 保留）；inline card fallback 塞 `<div flex:1 minWidth:0>` slot（仿 ErrorBanner.jsx 风格：radius 10 + T.warn/err 边框 + 重试）。

## 5. 验收标准（给标准不给步骤）

1. **App 级**：某屏 render 抛异常（可注入测试）→ **全屏 KNOT 降级屏**（非白屏）+ 重试钮 reload；error_reporter 收到上报（有 token）。
2. **ResultBlock 级**：某历史 msg 的 ResultBlock render 崩溃 → **该 msg 位置 inline error card**，其余 msg + composer + 输入正常；崩溃隔离单 msg（key）。
3. **透明性**：正常使用（无崩溃）—— 18 屏 + chat 全流程 byte-equal 视觉/行为；light+dark 双主题降级屏视觉正确（自读 cb_theme）。
4. **上报**：`reportError` 复用节流（同 hash 1h/5min/50page 上限）；window.error 既有上报 byte-equal（重构不改行为）。
5. build ✓ · eslint 0 · check_file_sizes OK · 5 源点 + doc-invariants 绿。
