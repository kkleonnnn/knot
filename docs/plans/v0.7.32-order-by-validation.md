## 2. Grounded 根因（Agent A · file:line）

`_order_limit`（`compile_helpers.py:115-130`）：
```python
def _order_limit(lf) -> str:
    out = ""
    if lf.order_by:
        obs = [f"{o.get('field', '')} {'DESC' if ... else 'ASC'}"
               for o in lf.order_by if o.get("field")]      # ⚠️ field 裸拼，0 校验
        if obs:
            out += " ORDER BY " + ", ".join(obs)
    ...
```
- **唯一已强制的 alias-based 校验先例 = `_outer_expr`（compiler.py:284 R-SL-120）**：`if not arg or arg not in set(lf.metrics) | set(lf.dimensions): raise`。having（`_having_clause`）/ window（`_window_col` 的 order_by/partition_by）**也只文档约定未强制**（同类 gap，非本刀 scope）——**手册引 R-SL-120 作先例，勿 overclaim having/window 已校验**。
- **合法字段集**（`_finalize` 三层 SELECT 可见列并集，qualify 只加 WHERE 不加列 → 单一集覆盖全层）：`set(lf.metrics) | set(lf.dimensions) | {w.get("as_name") or w.get("func") for w in lf.window}`。
  - metric name == 输出 alias（`AS {name}`，单/多对象 build 一致）；dimension name == 输出列名（`o.{d}`）；window as_name **缺省回退 `func` 名**（`_window_col:136` `w.get('as_name') or w.get('func')` — **镜像此回退，否则漏判 as_name 省略的窗口**）。
  - 纯 `lf` 可算（**0 catalog / 0 sibling import**，守 compile_helpers leaf 约束 Contract 9）；`_order_limit(lf)` 签名不变。
  - multi_base 2 调用点（multi_base.py:48/84）`lf.window==[]`（R-SL-101 gate）→ 集自然降级 `metrics∪dimensions`，无需特判。
