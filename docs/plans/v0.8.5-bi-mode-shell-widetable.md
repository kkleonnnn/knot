### R-BI-11 公式求值安全（承重 · grounding `wvb7zc7nx` + 守护者 §B）
公式覆盖是 admin 授权文本进求值器——**手写 tokenizer → 递归下降 parser → 白名单 evaluator**，镜像 `fragment_guard.py`「parse→校验白名单→fail-closed」纪律，**禁引入 npm 电子表格库**（违 R-186；版本漂移攻击面）。
- **R-BI-11.1 零 `eval`/`new Function`/`exec`/`with`/模板串求值**——全仓 100% eval-free，加 **CI grep 门**守住（**白名单 `RegExp.exec`** — `ThinkingCard.jsx:37 tableRe.exec` 合法，否则误红）。
- **R-BI-11.2 fail-closed**：任何无法识别的 token/函数/引用/解析失败 → 拒算 + 报错，**不 permissive fallthrough**（不抄 sql_validator fail-open）。
- **R-BI-11.3 无外部 parser 版本依赖**：手写固定文法 = 无版本漂移攻击面。
- **R-BI-11.4 纯客户端 + 无动态属性逃逸**：只在**已 fetch、已脱敏** grid 上算；无端点/网络/storage/DOM。A1 引用 / SUMIF criteria / cell-map **按数组下标 / `Map` / `Object.create(null)` 存取，严禁 plain-object 动态键（`obj[userStr]`）**（否则 `criteria='constructor'`/`__proto__` 经动态属性访问逃逸）；显式拒 `__proto__`/`constructor`/`prototype` 标识符。
- **R-BI-11.5 DoS + 环护栏（守护者 GAP-1 拆两护栏）**：(a) **parser AST 嵌套深度**上限（镜像 `_MAX_PAREN_DEPTH`）+ 公式长度 ≤500 / token 数 / range 大小 硬上限；(b) **⭐ cell 引用图环检测**（cell A `=B` / B `=A` → resolve 无限递归/栈溢出，与 parser 深度**正交**，fragment_guard 无此面）：求值维护 visited-set，命中环 → **fail-closed raise**。
- **R-BI-11.6 白名单函数集**：`SUMIF` + `SUM/AVG/COUNT/MIN/MAX` + 算术 + A1 单元格/区间引用；SUMIF criteria 按纯字符串/数值比较，**不当代码/正则**。
- **R-BI-11.7 存储侧再校验**：公式串持久化则读取/下发前经同 parser 重校验，**永不信任已存串**；公式 CRUD 配 AuditAction（并入 R-BI-8）。
- **R-BI-11.8 A1 求值语义（守护者 GAP-2 · kk 拍板）**：① **越界引用**（公式写 `B4:B28` 但 grid 行数不足）→ **越界单元补 0/空（Excel 手感，kk 2026-07-07 拍板）**；bounds-check 仍按数组下标（越界返 0，非 throw、非属性访问）——**仅越界补 0，其余非法（未知 token/函数、环、__proto__、超长）仍 fail-closed**。② **公式 cell 可引用其他 cell（含公式 cell）**，递归 resolve + memo，环由 (b) 检测；A1 行号寻址**渲染 grid 行**（header=row1 起，与 kk 截图 `B4:B28` 对齐）。③ **non-finite**（NaN/±Inf，如除零）→ 该 cell 显**错误标记**（不静默补 0、不崩）。

### R-BI-12 导出注入中性化（BI 路径）
导出 CSV/xlsx 时**导出计算结果值（非公式串）**；文本单元格首字符 `= + - @ \t \r` 前缀 `'` 中性化。**BI 导出路径独立中性化**（共享 `export_service` 通用修复已由 `v0.8.4` chore 落，见 §附录 B；BI 路径复用同规则）。

## §4 数据模型 DDL 草案（greenfield · `knot/repositories/schema.sql`）

```sql
-- 报表文件夹（层级 + 排序；admin 管理）
CREATE TABLE IF NOT EXISTS report_folders (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  name        TEXT NOT NULL,
  parent_id   INTEGER,                     -- 自引用层级；NULL = 顶层。soft ref
  sort_order  INTEGER NOT NULL DEFAULT 0,
  created_at  TEXT DEFAULT (datetime('now','localtime')),
  created_by  INTEGER NOT NULL             -- admin user id
);

-- BI 报表（②a 仅 wide_table；dashboard tiles 留 ②b）
CREATE TABLE IF NOT EXISTS bi_reports (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  report_type    TEXT NOT NULL DEFAULT 'wide_table',  -- 'wide_table' | 'dashboard'(②b)
  title          TEXT NOT NULL,
  folder_id      INTEGER,                  -- soft ref → report_folders；NULL = 未归档
  sort_order     INTEGER NOT NULL DEFAULT 0,
  data_source_id INTEGER,                  -- 绑业务库（OOS-1；refresh 用它解析 engine）
  sql_text       TEXT NOT NULL,            -- admin 直写、过 doris._is_safe_sql 只读闸（R-BI-5/D7）
  column_config  TEXT,                     -- JSON 列级：{col:{label,unit/format,frozen:bool,width}}（可空 → 用 SQL 别名）
  overlay_config TEXT,                     -- JSON 单元格/行级：[{row_index:int|null, col, kind:'text'|'formula', value}]
  -- 冻结快照（byte-镜像 saved_reports 263-266）--
  last_run_at        TEXT,
  last_run_rows_json TEXT,                 -- 冻结 rows[:200] JSON（定位式 → row_index 稳定）
  last_run_truncated INTEGER DEFAULT 0,    -- 1 = 触 200 行截断（宽表 ~28 行罕见）
  last_run_ms        INTEGER DEFAULT 0,
  refresh_seq        INTEGER NOT NULL DEFAULT 0,  -- 每次刷新 +1 → UI 标覆盖层 staleness
  last_run_by        INTEGER,              -- 触发者（admin id 手动；②c 调度 sentinel）
  created_at     TEXT DEFAULT (datetime('now','localtime')),
  created_by     INTEGER NOT NULL          -- admin user id
);
```

> 幂等 CREATE TABLE IF NOT EXISTS。`overlay_config` **独立于** `column_config`。覆盖行 `row_index` 只对冻结快照稳定 → `refresh_seq` bump 时若行集变化，UI 标覆盖层可能过期需 admin 复核。复用 `_LAST_RUN_ROW_LIMIT=200`。

## §6 验收标准

1. **模式切换**：BI/ASK 来回切；ASK = 现有 Chat 逐像素不变（byte-equal 验证）。
2. **目录**：admin 建/移/改序/删 文件夹 + 报表；analyst 看同目录**无写入口**（按钮不渲染 + 后端 403 双保险）。

5. **冻结/刷新**：进屏读快照不打 DB；admin 重跑 → 重执行 SQL + `refresh_seq` +1；analyst 无重跑入口。
6. **权限后端**：analyst 直调写端点 → 403；SQL 非只读 → **存前预校验拒**（D7 `is_safe_sql`）；非 admin 读响应**不含 sql_text**。
7. **导出**：BI 导出注入中性化（`=SUMIF` 文本前缀 `'`）；导出公式**结果值**非公式串。
8. **闸门全绿**：backend pytest（BI service/repo/api + 公式 evaluator 对抗测 + **自建** `test_metric_invariant_guards` bi_report./report_folder. per-literal guard）· vitest（公式 evaluator 单元 + 对抗）· lint-imports 9 · **doc-invariant 全绿（5 test）** · R-94（含预声明 ACK）· eval-free grep · **18 屏 + saved_reports/Chat/TableContainer git diff 0** · 视觉 token 无硬编。
