### §2.1 决议
echarts ^6 全量 `import * as echarts from 'echarts'`（Shared.jsx:7）→ `echarts/core` 按需（tree-shake 掉未用 chart/component/Canvas renderer）+ vite manualChunks 把 echarts 切独立 vendor chunk（缓存稳定）。节省 ~600-700KB raw / ~180-220KB gzip（bundle 1.56MB → ~0.85-0.95MB），Login 首屏同步受益。

### §2.2 文件改动（精确）

   ```js

   import { LineChart, BarChart, PieChart } from 'echarts/charts';
   import { GridComponent, TooltipComponent, LegendComponent } from 'echarts/components';
   import { SVGRenderer } from 'echarts/renderers';
   echarts.use([LineChart, BarChart, PieChart, GridComponent, TooltipComponent, LegendComponent, SVGRenderer]);
   ```
   `echarts.init` / `.setOption` / `.dispose`（L452/510/560 等）**全不改**（core+instance API 在 use() 后齐备）。
2. **`frontend/vite.config.js`**：`build.rollupOptions.output.manualChunks`（函数式：`id => id.includes('node_modules/echarts') ? 'echarts' : undefined`）。
