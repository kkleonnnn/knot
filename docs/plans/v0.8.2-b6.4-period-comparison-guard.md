## §1 决议（Stage 3 整合后）

### 1.1 核心立场：**curated 标记集确定性拒识 = 激活门 interim 必修**；根治=唯一完整闭合(defer)；散文半→B6.5

- **激活门 interim 必修 = 近期「堵」**：拒识 → `engine=llm` → 无徽标 → 不再「命中」→ **该类结构 误判关闭**。
- **⚠️ 守护者 B-2 重构（中心）**：拒识**不等于**同环比误判在生产上 = 0，只是**降到「curated 标记集/corpus 措辞覆盖 = 确定性关闭，novel 措辞 = 残余」**。curated regex **非穷尽**（守护者 regex-over-真corpus POC：`本周和上周新增用户数对比`、`今天 vs 昨天 GMV 对比` 等**真 corpus 串逃逸** → 静默丢 → HIT → 误判照旧泄漏）。**真完整闭合 = 根治 LogicForm compare 字段（defer）** —— compare 字段不是「能力 nice-to-have」而是**误判唯一完整闭合**。
- **根治**（compare 字段 + compiler 当前-vs-prior）= **defer 后续 v0.8 feature PATCH**（YoY-标量 contained：same_period_last_year 窗已 resolved + conditional-agg 分支；但引风险回 B6.1 级 + 需对抗）。
- **散文 overclaim 半 = B6.5**（回退后 engine=llm 已非语义层误判）。**明示 kk：回退后散文仍可能说「同比」≠ 激活门失败。**

### 1.2 ⭐ 拒识机制：确定性 post-parse guard（跑**原始** question）+ prompt nudge

**guard（承重）**——位置 + 输入经守护者 B-1/B-3 钉死：
- **输入 = 原始 `req.question`（守护者 B-3）**：`run_semantic_compile_step` 现仅收 `refined_question`（`query_steps.py:152`，clarifier LLM 改写产物；clarifier.md 只锁相对时间词 verbatim、**不锁对比标记** → 「同比上周」可能被改写成「与上周做比较」使 regex 漏）。**∴ guard 须跑原始 NL（用户对比意图的 ground truth，非 LLM 变量）** → **query.py 加传 `req.question` 进 run_semantic_compile_step**（新增 raw_question 参数；现 `query.py:409` 只传 refined_question）。
- **位置 = `try` 块内、`compile_logicform`(`query_steps.py:198`) 调用之前（守护者 B-1）**：guard raise 的 `CompileError` **须被 `:199 except` 捕获** → near-miss 行 + 回退。⚠️ **严禁**放在 `try`(`:197`) 之前（如 lf 处理块 :184-196，在 try 外）→ 否则 CompileError **逃逸成 500，回退全废**（镜像 compiler.py:334 `_guard_fragments` 在 compile 体内 splice 前的位置）。
- **判据 = 单表达式（守护者 §D-2）**：`bool(_COMPARE_RE.search(raw_question)) and not _has_lag(lf.window)` → raise CompileError。**严禁**「regex 命中即 raise、后置查 lag」（会误拒合法 lag date-series）。`_has_lag` = `any(w.get("func") in ("lag","lead") for w in lf.window)`。
- **确定性**：给定原始 question + LF，判据是纯函数 → curated 标记集内 deterministically 拒。**保留 环比-lag date-series**（有 lag → 不拒；守护者 POC 验 `GMV每日环比`+lag → 不拒）。

**prompt nudge（软化，非承重）**：`parser.py:56` 现「环比→lag」示例与拒识冲突 → 收窄「**仅 date-series 明细环比用 lag；标量跨期对比/同比 → 输出 `{metrics:[]}` 回退**」（镜像 `:33`）。减 guard 触发频率 + 减 LLM 幻觉 lag。guard 是硬底线、prompt 是优化。

### 1.3 拒识路由 = CompileError → near-miss 审计行（守护者 §D-4）
经 `query_steps.py:199-201` 写 `semantic_query_audit` near-miss 行（`compile_error_reason="跨期对比语义（同比/环比）未在 LogicForm 表达 → 拒识回退（B6.4；根治待周期对比字段）"`）→ 回退 LLM。**诊断可见**（区分拒识 vs 静默 miss）+ **B6.2 fallback case 联动**（同比 question → 确定性 correct_fallback）。

### 1.4 regex 假阳/假阴精修（守护者 §C，落码集）
- **假阳（护 byte-equal）**：词边界 + `MoM` 大小写锚 + `环比(?!例)` 负向（防 `循环比例`）+ **metric/dimension name allowlist 预扣**（标记恰是注册 metric/维度名子串 → 不拒，防未来业务词含「同比例」「去年同期」误拒）。当前真 corpus 6 命中无一走语义命中路径（byte-equal 未破），但作无边界 2 字子串对未来业务词有 latent-FP → 必护。
- **假阴（扩集闭高频）**：`(和|跟|与)\s*(上周|上月|去年|上季|去年同期)\s*(比|对比|相比|比较)` · `(今天|本周|本月|今年)\s*vs\s*(昨天|上周|上月|去年)`（现 `vs` 仅接「上周|上月」漏「昨天/去年」）· `相较(去年|上月|上周)` · `(上周|上月|去年).{0,6}(这周|本月|今年).{0,4}(对比|比)`（两窗并陈）。
