## §2 relocation 状态机（`relocate_uploads_once`，独立 · MF1/R3/R4/R5/G2）
入参：data-root（`SQLITE_DB_PATH.parent`）+ 当前租户 uploads 目标路径（`_tenant_uploads_path()`）。持 C4 同一 flock（外层已持）。
- **same-path**（db_dir='.'，target==源，测试）→ skip:same-path
- **源无 + target 无** → skip:fresh（租户从未上传 · **合法空**）
- **源无 + target 有** → skip:relocated（已迁）
- **源有 + target 无** → relocated（首迁）
- **源有 + target 有(本迁移残留/带 `.uploads-relocating` marker)** → resumed（覆盖重迁）
- **源有 + target 有(真数据 且 无 marker)** → raise（疑似违反铁律先上现网 → 拒覆盖）

crash-safe（**复用 C4 Stage-4 硬化版 `_backup_db`：严格 `_fsync_file` 失败即 raise，非既有 `_migrate_uploads_to_isolated` 的弱 `shutil.copy2`+best-effort checkpoint**，G2）：
① 置 `.uploads-relocating` marker → ② `.backup()` 源 → target（WAL-safe+fsync）→ ③ **校验**（详下）→ 过才 ④ 当场新建 **`uploads.db.pre-v0.9.2-relocation.bak`**（硬化 `_backup_db`，非依赖 stale `.pre-tenancy.bak`，R5）→ ⑤ 删源+`-wal/-shm`+fsync 目录 → ⑥ 清 marker。resume 前既有真数据 target → `.pre-resume.N.bak` 保全（镜像 C4 must#2）。
**校验（MF4/R4 关键 nuance — uploads.db 可合法零表）**：**不复用 C4 `_db_wellformed`/`_verify_migrated_db`**（它们要求 ≥1 表 / 关键表，会误拒合法空 uploads）；改：源+target `quick_check` ok + **精确表集一致** + 逐表行数一致 + **metadata↔physical**（当前租户 `file_uploads.table_name` 全在 uploads DB）；合法零表**仅当 file_uploads 也空**才过。

## §3 关键设计 / 铁律
- **⭐ MF1 独立无条件**：relocation 在 `_migrate_locked` 返回后同 flock 无条件跑（除非 knot 迁移 raise）—— 真实升级 anchor 已迁走走 skip:migrated 也照迁 uploads。
- **⭐ G3/MF10 时序 + 拒覆盖**：❷.5 先 relocation（root→tenant，搬**已隔离** t_*）→ 再 per-tenant init_db 的 `_migrate_uploads_to_isolated`（搬租户 knot.db **残留** t_*）。两者都写 `tenants/1/uploads.db` → init_db 侧同名 t_* **拒无条件 DROP**（先比 schema+行数，防用旧 knot.db 副本覆盖 relocation 的，MF2）。
- **⭐ 铁律延伸**：uploads relocation **同 C4 必先于现网 rollout**（否则 resolver 指 tenants/1/uploads.db 而数据在 root = 上传问数空库 + 孤儿）。DEPLOY 迁移段补 uploads + 回滚**反向快照**（迁后新增上传须回搬，别默认恢复陈旧 bak，MF8/R10）。
- **MF5 memoize/路径安全**：`(tid, canonical_abs_path)` 键 + path 在数据根内 + path→tid tripwire；db_dir UNIQUE 是 R-T-GATE 前置（未成立）。
- **单租户 byte-equal**：db_dir='.' → `_tenant_uploads_path`=data-root/uploads.db（同现 `_UPLOADS_DB`）→ 行为不变。
- 退役 `_migrate_uploads_db_once`（吞回主库）**严禁重接**（守 Stage 1 §2）。
