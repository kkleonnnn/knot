## §B ⭐ 最值钱的一条：**第三种伪装 —— 压根不在的那个**

kk 2026-08-07 立的判据是「清扫所有同类的 X，最容易漏的两类是**被声明为无关的**和**形态不同的**」。
本轮出现**第三类**，由 lens B 提出，执行者复核成立：

> **同类里最危险的成员不是「另一份名单」，而是「没有名单的那条出网路径」——
> 按「找名单」的扫描面，结构上找不到它。**

**实证**：`knot/api/admin/datasources.py:19` 的 SSRF 守卫**函数体第一行**是
`if db_type != "http" or not http_config: return` ⇒ **SQL 数据源那条出网路径零 allowlist**。
`api/database.py` 的 `POST /api/db/test` 直接拿租户 admin 填的 `db_host/db_port` 建连接并把错误消息返回
⇒ 内网端口扫描 + banner grabbing。

⇒ **判据要改**（建议折进 CLAUDE.md，替换原拟的两类版本）：
> 清扫「所有同类的 X」时，**先列出「所有需要被 X 管住的行为」，再看哪些没被管** ——
> 只扫 X 的实例，找不到「X 应该在而没在」的那些位置。
> 三种伪装：**被声明为无关的** · **形态不同的** · **压根不在的**。

| 伪装 | 实证 | 谁漏的 |
|---|---|---|
| 被文档标注「独立 / 无关」 | `KNOT_WEBHOOK_ALLOWED_HOSTS`（docstring 自称「≠ 数据源那个」） | v0.9.7（kk 自陈） |
| **形态不同** | `TTLCache(...)` 非字面量 · `@lru_cache` 无赋值语句 | 执行者（两次） |
| ⭐ **压根不在** | SQL 数据源出网无 allowlist | 三 lens 中仅 1 个找到 |

## §C 阻断项（执行者已逐条自核 · 全部 ✅ 确认）

### C1 · 域化会把 allowlist 变成装饰品（**本片新造的危害**）
**证据**：全仓**只有** `api/admin/datasources.py:71` 写了 `allow_redirects=False`。
`webhook.py:55` · `lark.py:42` · `telegram.py:52` · `executor.py:116,118` **全部跟随重定向**。
**场景**：域化后运维给租户 B 配 `allowed_webhook_hosts='hooks.b.example'`（B 自己的域名，完全合规）
⇒ B 让该 host 返 **308** → `http://10.0.0.5:8080/x`，requests **原样重发 POST body**
⇒ 本片刚建的边界零成本绕过。
⭐ **域化之前这条路不成立**（allowlist 里只有部署方自己的 host，不听租户的话）
⇒ **这是「域化会不会产生新危害」的答案：会，而且是把 allowlist 归零。**
**连带**：`url_allowlist.py` 自认只比 hostname 字面，无私网/IP 字面/DNS-rebinding 判据。
⚠️ **Stage 1 §4.2 的正对照会在边界坏着的时候通过。**

### C2 · 「新列无写端点」是**事实错误**（Stage 1 §2/§3.6）
**证据**：`api/platform_admin.py:238` `allowed_http_hosts: str` **必填无默认**（缺则 422）；
`repositories/tenant_provisioning.py:126,182` INSERT 明写该列；
`repositories/tenant_repo.py:117 _MUTABLE_TENANT_FIELDS` 也含它 ⇒ **已有两条写路径**。
**后果**：只加列 + 迁移而不改这两处 ⇒ **每个经 API 开通的租户新列恒 NULL ⇒ 其 webhook 全静默拒**
—— 正是 v0.9.15 花力气消除的失败模式在新列上原样复活。
⚠️ 而 `platform_admin.py:229` 正写着「**刻意不给默认值** —— 否则开通动作就替部署方静默选了一种语义」
⇒ **本片会原样重犯它刚立的规矩。**

### C3 · 审计脱敏**硬编单个列名** ⇒ 新列内容会泄进平台审计
**证据**：`tenant_repo.py:208` `if k == "allowed_http_hosts": detail[k] = "changed"`（**硬编单名**）。
新列进 `_MUTABLE_TENANT_FIELDS` 而不改这行 ⇒ webhook allowlist **内容**原样进
`platform_audit.detail_json`，经 `GET /api/platform/audit` 读出（#262 同族）。
⚠️ **无哨兵顶班**：`tests/test_platform_audit.py:110` 内容级断言**写死旧列名**；
`:279` 只查 env 读、而新列是 DB 来源 ⇒ **两条都不会红**。
⇒ 这是 v3.1-B #3「层对了但入口不止一个」的又一实例。

### C4 · Stage 1 §3.1 答反了
原文：「本片**不**引入新的『唯一』依赖」。
**实际**：起源租户 env 回退**本身就是**「回退到唯一对象」，而本片正要新增一处。
⇒ 与 CLAUDE.md 已记的 v0.9.16 现场实例同形，**须显式登记进那份「清单必须派生」的账**。
