## §1 两个缺陷（已逐行复核）

### D1 · webhook 出网未租户域化
`webhook.py:26` 读进程 env `KNOT_WEBHOOK_ALLOWED_HOSTS`；生产调用点**恰 1 处**
（`api/admin/monitors.py`，monitor 行在**租户库**）。与 v0.9.7 修掉的 `url_allowlist` **完全同形**。
⭐ **它逃过 v0.9.7 清扫的机制**（kk 自陈）：docstring 明写自己「**独立** egress allowlist，**≠** 数据源那个」
—— **被标注为「与正在修的那个无关」的同类物，结构上就被那次修复的扫描面排除了。**

**危害订正**（Stage 2 lens C，比初版准）：body 是租户 B **自己的**指标值 ⇒ 出去的**不是别家数据**。
真正的受害者是**部署方**：
- allowlist 里通常是部署方自己的告警 webhook ⇒ B 可往运维群**注入任意文本**（`m["name"]` 由 B 控）= 钓鱼/社工；
- **失败信息回给调用方**：`webhook.py:62` → `monitors.py:129 detail += f"| webhook 失败: {e}"` → HTTP 响应 + 落 trigger 审计，
  而 requests 的 HTTPError 原文含**状态码 + 完整 URL** ⇒ B 对 allowlist 内 host 的**任意 path**
  （allowlist 只管 host）有 404/403/500/超时的判别力 = **内网路径与端口枚举 oracle**；
- **可用性 —— Stage 3 must-2 订正，比初稿严重得多**：
  实测 `KNOT_WEBHOOK_ALLOWED_HOSTS` 在 **DEPLOY / README 零命中**，仅 `.env.example:65` 且**被注释掉**。
  ⇒ 若现网从未设过它，`get_webhook_allowed_hosts()` 今天返 **∅** ⇒ **现网 webhook 已经全部被拒**。
  ⇒ **诚实表述**：不是「租户 B 的 webhook 废」，而是 **webhook 出网在现网可能整体是死功能，含起源租户**；
  **本片让它第一次可按租户配置**。
  ⇒ 这把本片从「修一条泄漏」变成「**域化 + 可能的首次启用**」。
  ⛔ **现网到底设没设，必须在实施前真去查 ConfigMap** —— 「现网行为逐字不变」是本片的一句声称，
  在查证回来之前**不得写下**。（执行者够不到内测服 ⇒ **该查证是 kk 的动作**；
  §4-3 的两支设计让实施不被它阻塞，但**声称**被它阻塞。）

### D2 · lark token 缓存：**命中缓存这条路上，secret 根本不参与**
`_tenant_token()`（`lark.py:54-58`）：`key=(region, app_id)` → `_token_cache.get(key)`
→ 未过期**直接 `return cached[0]`** → **只有 miss 时才带 `app_secret` 去 POST**
⇒ 参数 `app_secret` 在命中路径上**一次都没被读**。

> **定性：命中缓存时，调用方没有证明过任何东西。**

⚠️ **可达性诚实收窄**（lens C 逐处查）：`app_id` 在 KNOT 内**零跨租户泄漏面**
（`admin/share.py:26-30` 仅本租户 admin 可见 · 审计只记 key 名 · `LarkError` 不含 app_id）
⇒ 租户 B 须从**飞书后台 / 机器人所在群**等 KNOT 之外的渠道取得 `app_id`。
**缺陷本身成立且要修**，但**不是「一个租户 admin 坐在那里就能做到」**。

### D2
- 键 = **`tenant_cache_key(region, app_id, digest)`** —— 与其余 7 处缓存同一 helper。
  ⚠️ **不是** `tenant_cache_key(region, app_id) + digest`：该 helper 返 **tuple**
  （`tenant_context.py:135`），`tuple + str` 是 `TypeError`（Stage 2 E1）。
- `digest = sha256(app_secret)[:16]`（不存明文、不进日志）。**两个独立理由，缺一不可**：
  - **①（安全 · 承重）**：**secret 必须参与判定**。没有它，命中路径上调用方零证明。
  - **②（正确性）**：同租户换 secret 要**立刻生效**，而非等旧 token 自然过期（≤2h）。
  ⇒ 将来有人为省一次 hash 把 secret 摘出键时，**②看着还成立而①已经塌了** ⇒ 必须两条都写在代码注释里。

  `bi_share.py:78 except Exception` → 审计 + 502，**fail-closed 且响亮**，可接受。
