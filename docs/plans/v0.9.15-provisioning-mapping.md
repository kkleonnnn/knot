## §2 承重不变量（provisioning 必须不破）

1. **R-T-GATE 硬门只对 `active > 1` raise**（`tenant_repo.py:233-257`，判据原文实测）
   ⇒ ⭐ **开通出 `status='suspended'` 的租户不会触发它。**
2. **两个解析器都过滤 `status='active'`**：`resolve_tenant_by_id`（`:195`，B-2 承重）·
   `resolve_tenant_by_slug`（`:210`，登录路径）⇒ **suspended 行对请求路径与登录路径都不可见。**
3. **`UPDATE tenants` 全仓恰一处**（哨兵 `tests/test_platform_audit.py:375`，扫生产码）
   ⇒ ⚠️ 该哨兵**不约束 `INSERT INTO tenants`**（今天生产里恰好也只有 seed 一处）。
4. **`platform_audit` append-only**（禁改禁删）+ **action Literal 与 emit 精确集合相等**。
5. **新增平台列不得流进响应** —— 已有守护 `tests/api/test_platform_admin.py:300`
   （**两道独立投影**：`list_tenants_public()` + `response_model`）。
   ⭐ 那条测的 docstring **就是为本片写的**：「B-3 已排期给平台层加 … per-tenant 初始口令
   ⇒ 届时 `SELECT *` + dict 直转会**自动**把它们吐出去」。
   ⚠️ **我一度误报**：以为 `initial_admin_password` 列已存在（测里有 `UPDATE tenants SET
   initial_admin_password=…`）—— 实为**该测自己先 `ALTER TABLE` 注入的**（`:312`）。
   schema / 平台迁移 / 生产码**三处零命中** ⇒ 该列今天不存在。撤回误报。

## §3 缺什么（= 本片作业面）

1. **写端点 / CLI**：创建租户（`slug` / `name` / `db_dir` / `allowed_http_hosts`）。
2. **`db_dir` 约束**：无 `UNIQUE`（实测 schema）⇒ 两租户可指向同一目录。
   ⚠️ 已知不对称实测（v0.9.5 测绘）：同 `db_dir` 时**主库共用**而 `uploads` raise。
   另需**格式约束**（防 `../evil` —— `tests/test_uploads_tenant_isolation.py:231` 已有该形态的测）。
3. **起源租户保护**：`resolve_single_tenant()` 只要求恰 1 active、**不要求 `id == OWNER_TENANT_ID`**
   ⇒ 停用 tenant#1 + active tenant#2 ⇒ boot 成功而 **file 层对被服务租户静默变空**
   （v0.9.6 已加启动 WARN 兜可诊断性，根治登记在本片）。
4. **开通时必须显式配 `allowed_http_hosts`**：该列**无任何写端点**（E2）⇒ 今天唯一途径是运维
   直接 `UPDATE platform.db`；漏配 ⇒ 该租户 HTTP 数据源**全部静默拒绝**（fail-closed 正确，
   但**与 bug 不可区分**）。
5. **新租户的库**：`init_db()` 会建表 + 跑迁移 + **seed 一个 admin**（`base.py:66-`）。

## §4 ⚠️ 四个分叉 —— 都是 kk 的口径，我不擅自定

| # | 分叉 | 我的建议与理由 |
|---|---|---|
| **A** | 开通出来的租户是 `suspended` 还是 `active`？ | **`suspended`**。§2-1/2-2 实测：suspended 不触发 R-T-GATE、且对两条解析路径不可见 ⇒ **本片可在 lift 之前完整落地并测试**，「激活」成为 lift 门后的独立动作。 |

## §5 本片**不**声称（预先收窄）

1. **不放开第二租户服务**（lift 仍是独立片；本片只让「租户存在」成为可能）。
2. **不改 `resolve_single_tenant` 的 7 处生产调用点**（那是 lift 前置的另一项）。
3. **不做租户删除**（append-only 审计 + 数据销毁语义，独立评估）。
4. ⚠️ **不声称运维直连 `sqlite3` 改平台库会被审计** —— 同 v0.9.8 的诚实边界，只声称**代码路径**。
