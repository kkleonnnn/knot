## §2 权限模型（C，核心）

**目标 = 目录 或 单张报表**：
- 归档报表（`folder_id` 非空）→ 继承**所属目录**的角色授权（角色×目录）。
- 未分组报表（`folder_id` 空）→ **逐报表**角色授权（角色×报表）。
- **admin 恒全权**（不入权限表；`require_admin` 语义保留为 admin bypass）。

**4 权限 → 动作映射**（kk 确认「对」）：
- `can_edit` = 该目标报表的 增/改/删（create/update/delete_report）+ 手动重跑（refresh）
- `can_schedule` = 定时刷新（②c 调度器 fire 时校验；当前先 gate「定时」入口 UI）
- `can_export` = export.csv / export.xlsx
- `can_share` = 分享

**数据表**（schema.sql + base.py 幂等；软引用镜像 report_folders）：
```sql
CREATE TABLE IF NOT EXISTS bi_permissions (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    role         TEXT    NOT NULL,            -- 授权角色（当前非 admin = 'analyst'）
    folder_id    INTEGER,                     -- 二选一：目录级授权（软 ref report_folders）
    report_id    INTEGER,                     -- 二选一：报表级授权（软 ref bi_reports；未分组用）
    can_schedule INTEGER NOT NULL DEFAULT 0,
    can_edit     INTEGER NOT NULL DEFAULT 0,
    can_export   INTEGER NOT NULL DEFAULT 0,
    can_share    INTEGER NOT NULL DEFAULT 0,
    created_at   TEXT DEFAULT (datetime('now','localtime')),
    created_by   INTEGER NOT NULL,
    CHECK ((folder_id IS NULL) <> (report_id IS NULL))   -- 恰好一个非空
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_bi_perm_folder ON bi_permissions(role, folder_id) WHERE folder_id IS NOT NULL;
CREATE UNIQUE INDEX IF NOT EXISTS idx_bi_perm_report ON bi_permissions(role, report_id) WHERE report_id IS NOT NULL;
```

**解析** `effective(user, report, action)`：
```
admin → True
否则 → report.folder_id 非空 ? grant(role, folder_id).can_<action>
                          : grant(role, report_id).can_<action>   # 未分组
无 grant 行 → False（默认拒）
```

**后端强制**：新依赖工厂 `require_report_perm(action)`（读 path 里的 report_id → 解析 → admin ∨ perm，否则 403）。改造端点：
- update/delete_report、refresh → `edit`
- export.csv / export.xlsx → `export`（**收紧**：现为 get_current_user 全体可导 → 改 admin∨export）
- 分享端点（若有）→ `share`；定时（②c）→ `schedule`
- create_report → 目录级 `edit`（建在某目录内需该目录 edit；未分组新建 = admin only，因无 report_id 可授）

**权限管理 API**（admin）：`GET/PUT /api/bi/permissions`（按 folder_id / report_id 读写 grant）；audit `bi_permission.change`（新 AuditAction Literal + per-literal guard 扩）。

## §6 验收标准（不给步骤）

1. 从 BI 进设置只见 {全局项 + 目录管理 + 权限 + da-asst}；从 ASK 进只见 {全局项 + agents/prompt/catalog/模型}；互不串。
2. admin 全权；analyst 仅在被授权的目录/报表上能 编辑/定时/导出/分享，未授权 → 403 + UI 按钮不显。
3. 归档报表继承目录授权；未分组报表逐张授权生效。
4. da-asst 留空 key → 用平台默认（现行为）；填 key/模型 → 用之（加密存储）。
5. 全闸门绿；18 屏 + ASK + 现有 Admin byte-equal。
