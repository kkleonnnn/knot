## §2 决议

### D1 · 闸 = **外层 wrapper**（唯一 choke point，落在真路径上）
`catalog_loaders.py` 新增：
```python
FILE_CATALOG_OWNER_TID = 1     # G5：seed 硬编 + 迁移语义（= 多租户之前就存在的那个租户）

def load_file_layer() -> tuple:
    """owner-gate：**只有 owner 租户**拿到 file 层内容，其余返 empty 五元组（fail-closed）。"""
    from knot.core.tenant_context import current_tenant
    if current_tenant()["id"] != FILE_CATALOG_OWNER_TID:
        return {}, [], "", [], "empty"
    return _load_from_files()
```
- `catalog.reload()` 与 `get_defaults_from_files()` **都改调 `load_file_layer()`** ⇒ **单一 choke point**
  （避免「N 份清单」病：两处各判一次必漂移）。
- **无 ctx → `current_tenant()` raise**（fail-closed 且**响亮**）。G6 已证生产无无-ctx 调用者。
- ⚠️ **不引 env 开关**（如 `KNOT_FILE_CATALOG_OWNER_TID`）—— 又一个漂移源；且 owner 语义由 seed + 迁移
  结构性决定，不是部署偏好。**请 Stage 2/3 裁这个取舍。**

### D2 · owner 侧 **byte-equal**
`id==1` 路径逐字不变：三层 `real→example→empty`、v0.7.29b 的 file HTTP **权威覆盖**、
`source_type` 推断、`_SOURCE` tag 全部保持。**单租户部署（= 新部署恒 tenant#1）行为 0 变化。**

### D3 · 非 owner → **完整 empty 五元组**（不得半空）
`({}, [], "", [], "empty")`。**禁**只清 tables 留 lexicon/rules 之类的「半空」——
半空会让 `business_rules`（部署方业务口径）继续泄漏给别租户，正是本片要闭合的东西之一。

### D4 · 钉住 **②③ 不可达**（结构 + 行为两层）
- **结构**：AST 哨兵断言「全仓到 `adapters.http.execute` 的 import 只有 `http_planner`」
  ⇒ 「executor 唯一入口」这个前提不会被将来新增第二条路径静默破掉（G3 是本片全部推理的地基）。
- **行为**：非 owner 租户下 `get_http_tables()==[]` · `is_http_table(...)是False` ·
  `pick_http_route(...) is None` · 且**取材**：给非 owner 的 DB catalog 灌一张 http 表 →
  `pick_http_route` **应命中** ⇒ 证明「不可达」来自**槽里没有 http 表**，而不是别的巧合。
  ⭐ 这条反向取材是本片判别力最高的一处：它把「不可达」从「观察到 None」变成「**知道 None 的原因**」。

### D5 · R-T-GATE 清单指针**改写不删**
`CLAUDE.md` 的 B-3 三项：① 标**已闭合（owner-gate）**；②③ 改写为
「**对非 owner 租户结构性不可达**（G3）—— 真要给租户自己的 http 表时才需做」，
并**保留在清单里**（不是删掉）。同步 `tenant_repo.py:52` / `platform_admin.py:125` 两处提到 B-3 的注释。

### D6 · scope 外（kk 拍板）
**不做** per-tenant `http_spec` 凭据 · **不做** egress 租户域化 · **不碰** per-tenant Fernet key ·
**不 lift** R-T-GATE · **不动** `_template_catalog.py` 内容。
